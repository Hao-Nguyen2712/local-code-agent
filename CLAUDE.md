# Claude Code Project Instructions

Read `AGENTS.md` first.

This repository follows Spec-Driven Development.

Do not implement runtime features unless the related spec and task file exist.

For every coding task:
1. Read the relevant spec.
2. Read the relevant task file.
3. Write or update tests first.
4. Implement the smallest production change.
5. Run the test suite.
6. Show the final git diff.

Never implement out-of-scope features.
